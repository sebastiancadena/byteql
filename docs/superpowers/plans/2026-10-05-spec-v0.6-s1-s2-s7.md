**Goal:** Land the three v0.6 slices that need no user decision: engine hygiene (D10), the 0.4
spec-version floor (D8), and sound parent-key reachability with the message-table hop (D9).

**Architecture:** All three are version-independent engine changes in `packages/core`. No pack
spec changes, no new spec fields, no `version: '0.6'` literal (that arrives with S8). Every
shipped golden and schema snapshot must stay byte-identical.

**Tech Stack:** TypeScript, zod, vitest, pnpm workspace.

**Spec:** `docs/superpowers/specs/2026-10-03-spec-v0.6-pack-boundary-design.md` (sections D8, D9,
D10, "Migration plan" bar, "Sequencing" rows S1, S2, S7). Read E8, E9(a)-(c) for evidence.

  `/home/...` paths** in commits or files.

- Branch: `feature/spec-v06-foundations` off `main` (created before Task 1).

## Review Focus

1. A caller that passes an already-aborted signal must still get `AbortError` from the driver
   (making the signal optional must not drop abort support) — Task 1 keeps the existing abort
   tests and adds the no-signal test.
2. A flow that hits both a below-base retransmission and a released-history retransmission must
   report **both** codes, once each per flow (separate de-dupe flags) — Task 2 test.
3. A numeric YAML `version: 0.3` (unquoted, parsed as a number) must be rejected with the
   friendly floor message, not a generic zod union error — Task 3 test covers `0.3` and `'0.3'`.
4. A message table that is also fed by a non-stream dissect link (pcap's `dns` shape) must keep
   only keys present on both paths — Task 4 test.
5. A dissect rooted at a parser fed from two tables must still accept a `parent_key` onto a
   table both paths carry (must-reach must not reject the common ancestor) — Task 4 test.

**Interfaces:**

- Consumes: nothing new. `reachableByParser`, `reachableByTable`, `reachableByStream`, and
  `reachableAtEntry` keep their names and meanings for rule 7 and rule 9; only how the sets are
  computed changes.

**Semantics (from D9):**

- A node with no incoming contribution (a root table) has the empty set.
- A node with incoming contributions has the **intersection** of its contributions.
- Contributions: each chain link folds `reachableAtEntry(entry)` into its parser id, its table
  (if any), or its stream. Each stream folds its set into every message **parser** id and — new
  — every message **table**.
- Process contributions in topological order of their source node so every source set is final
  before it is read (the graph is acyclic by rule 11).

  const postorder: string[] = [];
  const detectCycle = (node: string): void => {
    if (visited.has(node)) return;
    if (visiting.has(node)) {
      throw new ProjectionCompileError(
        'PROJECTION_DISSECT_CYCLE',
        'dissect',
        `dissect graph has a cycle involving ${JSON.stringify(node)}`,

    visiting.add(node);
    for (const next of edges.get(node) ?? []) detectCycle(next);
    visiting.delete(node);
    visited.add(node);

  };
